# Books for the robot's book reader

Put plain-text books (`.txt`, UTF-8) here and ask the robot to read them ("read me Alice in Wonderland").
Project Gutenberg texts work as-is: the licence header and footer are skipped and chapters are detected.
With `--web`, the robot can also fetch a book from Project Gutenberg on request; it is saved here.

Everything in this folder except this README is git-ignored.
